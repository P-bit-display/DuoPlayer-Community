# 🗺️ DuoPlayer 功能演进路线图 (Roadmap) 与需求征集

DuoPlayer 秉持“专注折叠屏创新交互、极致硬件解码性能、对齐主流工业级成熟方案”的原则持续演进。

在此向所有公测用户与社区开发者公开近期的功能演进路线图，并欢迎大家在下方评论区针对想要的功能进行**投票（点赞 👍）**或提出新的需求建议！

---

## 🎉 已交付里程碑 (Recently Shipped)

### ✅ 原生系统级画中画 (Picture-in-Picture / PiP) 与竖屏多任务生态
- **交付状态**：已正式上线最新版本
- **核心体验**：
  - 🎥 **自动上划入画中画**：播放视频时从底部上划回桌面或切换应用，画面秒变浮窗悬停，音画零中断；
  - 🔘 **全场景快捷开关**：全屏控制栏与折叠屏触控台均提供原生 `pip.enter` / `pip.exit` 纯净按钮；
  - 🔄 **悬浮窗无缝还原**：在微信/小红书等外部 App 点击小窗返回按钮，毫秒级平滑弹回 DuoPlayer 完整界面并无缝接管播放进度；
  - 📱 **展开竖屏多任务协同**：将小窗磁吸贴在上半屏，下半屏畅快打字聊天、刷小红书动态，打造极致双屏生产力与娱乐体验。

## 📌 当前正在推进与调试中 (In Progress)

### 1. 💾 外接大容量 U 盘直存与文件导出 (USB Drive Direct Cache)
• **背景**：已完成底层安全作用域书签管理、后台断点续传及文件转存协议。  
• **当前状态**：为保证主流程高可靠性，当前版本通过 `isUSBDriveFeatureEnabled` 进行安全隔离。  
• **后续计划**：完善针对不同芯片转接坞（USB-C Hub / Lightning OTG）的插拔检测与错误提示，调试稳定后即刻开放。

### 2. 🎵 独立多音轨与多声道快捷切换面板
• **功能**：在折叠屏下半屏触控台及全屏播放层增加独立音轨切换气泡；  
• **特性**：自动识别并显示语言名称、声道数（如“国语 5.1”、“英语原声 Dolby Atmos”等）。

### 3. 🎬 智能片尾跳过与无缝自动连播
• **功能**：播放至最后 30~45 秒（片尾滚动字幕）时，在画面右侧浮出下一集预览小窗并提供“跳过片尾”一键播放下一集。
