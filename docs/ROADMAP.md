# DuoPlayer 社区需求征集

这里收集使用场景，方便大家讨论开发优先级。具体版本的交付内容请查看 [App Store 版本记录](https://apps.apple.com/us/app/duoplayer-video-player/id6830926628?l=zh-Hans-CN)。

| 讨论方向 | 最有帮助的信息 |
| --- | --- |
| 外接存储与离线播放 | 希望从移动硬盘直接播放，还是把已下载的影片转存到硬盘？ |
| 音轨、字幕与连续播放 | 切换语言、跳过片尾或进入下一集时，哪一步最费操作？ |
| 折叠布局与手势 | 使用什么姿态？手指要跨过画面才能点到哪个控件？ |
| 其他媒体服务器 | 你使用什么服务器，最希望先支持哪个操作？ |

到[需求征集帖](https://github.com/P-bit-display/DuoPlayer-Community/issues/2)给相同场景点赞，或说明你通常怎么操作、哪一步受阻。这里的讨论方向尚无公开交付日期。
