### 2. Common Setup Guides
- **Jellyfin / Emby:**
  - Endpoint format: `https://your-server-domain.com` (HTTPS) or `http://192.168.1.x:8096` (LAN HTTP).
  - Credentials: username and password, or an API Key generated in Jellyfin Dashboard -> API Keys.
  - Remote access: Make sure "Allow user to connect remotely" is checked in Jellyfin Dashboard -> Users if connecting over domain/cellular.
- **WebDAV (NAS / Alist / Cloud Storage):**
  - Endpoint format: `https://nas.domain.com:5006` or `http://192.168.1.x:5244/dav`.
  - HTTP Range streaming is automatically negotiated for smooth scrubbing and seeking.
